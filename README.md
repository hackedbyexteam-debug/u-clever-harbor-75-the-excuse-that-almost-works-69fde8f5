# The Excuse That Almost Works

A make.fun bounty entry: the one line a gamer texts the boss to skip work on GTA 6 launch week — one line, at most 20 words, written like a real hurried text.

## The entry

> Sorry, my preorder delivery needs a signature and the courier only comes between nine and one.

16 words, 94 characters. A delivery that needs a signature and a narrow courier window is a real, specific, boring logistical detail — the kind a tired manager has heard before and cannot easily disprove. And on launch week, of course the "preorder delivery" is the one thing that cannot wait, yet the text never names the game.

## Run

```sh
node main.ts
```

Writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), guarded to the competition's 140-character gate and 20-word cap.
